# Музыкальный плеер (Music Player)

Индивидуальный проект — паттерн проектирования State (Состояние)

Автор: Щербакова Кристина, ПИ-251

---

## Задача проекта

Сделать музыкальный плеер, который умеет:

- Воспроизводить треки
- Ставить на паузу
- Останавливать
- Переключать следующий и предыдущий трек

При этом плеер помнит, в каком он состоянии — играет, на паузе или остановлен — и ведёт себя по-разному в каждом состоянии.

Реализация: консольное приложение на C# (.NET Framework 4.7.2)

---

## Зачем это нужно в жизни

Представь, что ты слушаешь музыку через приложение. Кнопки Play, Pause, Stop работают по-разному в зависимости от того, что сейчас происходит:

- Если трек играет → кнопка Pause ставит на паузу
- Если трек на паузе → кнопка Play продолжает
- Если трек остановлен → кнопка Play начинает заново

Такую логику удобно реализовать через паттерн State — каждое состояние (Playing, Paused, Stopped) это отдельный класс со своим поведением.

---

## Паттерн State (Состояние)

### Зачем он нужен

Без паттерна пришлось бы писать кучу if / else и проверять состояние в каждом методе. Код стал бы запутанным и сложным для изменений.

### Что даёт State

| Ситуация | Как решает State |
|----------|------------------|
| Разное поведение кнопок в разных состояниях | Каждое состояние отдельный класс |
| Легко добавить новое состояние | Просто создать ещё один класс |
| Состояния не путаются друг с другом | Логика изолирована |

### Как устроено

- IPlayerState — интерфейс для всех состояний
- PlayingState, PausedState, StoppedState — конкретные состояния
- Player — сам плеер, у которого есть текущее состояние

## Как пользоваться

После запуска появляется меню:

=== MUSIC PLAYER ===
State pattern - Playing/Paused/Stopped

=== COMMANDS ===
1. Play
2. Pause
3. Stop
4. Next track
5. Previous track
6. Show playlist
7. Show status
0. Exit

### Что делает каждая команда

| Команда | Что происходит |
|---------|----------------|
| 1. Play | Начинает играть текущий трек |
| 2. Pause | Ставит на паузу (если трек играл) |
| 3. Stop | Останавливает воспроизведение |
| 4. Next | Переключает на следующий трек |
| 5. Previous | Возвращается к предыдущему треку |
| 6. Show playlist | Показывает все треки с отметкой у текущего |
| 7. Show status | Показывает состояние плеера и текущий трек |
| 0. Exit | Выход из программы |

## Как работает паттерн State

Вот как состояния переключаются:

        STOPPED
           |
           | (Play)
           V
        PLAYING <----> PAUSED
        (Pause)        (Play)
           |
           | (Stop)
           V
        STOPPED

### Что делает каждое состояние

| Состояние | Play | Pause | Stop | Next / Previous |
|-----------|------|-------|------|-----------------|
| Stopped | начинает играть | нельзя (сообщение) | уже остановлен | переключает трек (без воспроизведения) |
| Playing | уже играет | ставит на паузу | останавливает | переключает трек |
| Paused | продолжает играть | уже на паузе | останавливает | переключает трек и начинает играть |
